# Hyde

Hyde aims to be a XAMPP like stack written completely from scratch using ECMAScript / Node.js

It will convert Markdown into HTML and host it using built in web server 

The markdown will include the custom scripting language and following PHP philosophy, it will run on the server side

The project will also include a database for persistant data

## Fractal

The scripting language of the stack

## Hawk

The web server of the stack

## LoCache

Caching service of files for the web server

## Marker

The Markdown to HTML convertor of the stack

## Mytharis

The database of the stack
